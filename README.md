# Персонализированный AI-ассистент утреннего экрана (Кейс №1)

Интеллектуальный сервис для анализа пользовательских привычек за 90 дней и динамической генерации персонализированного утреннего дашборда. Система объединяет глубокий анализ поведенческих паттернов с генеративным пользовательским интерфейсом (подмножество **A2UI**), подбирая релевантные виджеты и формируя ответы с учетом контекста, календаря и целей пользователя.

---

## Ключевые возможности

* **Долгосрочная память (90 дней):** Анализ истории событий пользователя за последние три месяца, выявление устойчивых закономерностей, трендов и смены привычек для точных ответов на вопросы.
* **Динамический UI (A2UI):** Автоматический подбор от 1 до 4 наиболее актуальных виджетов для утреннего приветствия на основе расписания в календаре и текущих целей.
* **Каталог из 12 виджетов:** Проработанная библиотека UI-компонентов (от `sleep_card` до `restart_card`) с дружелюбным UX-копирайтингом без нравоучений.
* **Безопасность и соблюдение лимитов:** Интеллектуальный батчинг запросов к LLM (`gpt-6-luna`), укладывающийся в жесткие квоты API, а также встроенная фильтрация медицинских терминов.
* **Строгая валидация и оптимизация:** Гарантированное соответствие выходных данных JSON-схеме (`Case1Answers.schema.json`) при минимальном потреблении ресурсов.

---

## Технологический стек и архитектура

* **Backend:** Python, FastAPI, Pydantic / JSON Schema
* **AI / LLM:** `gpt-6-luna`, кастомный пайплайн батчинга и RAG/Memory-модуль
* **Frontend:** React, декларативный рендеринг на базе подмножества A2UI
* **Design:** UI-кит из 12 виджетов, интерактивный прототип дашборда

### Поток данных (Data Flow)
1. **Сбор данных:** Сервис забирает входной датасет через эндпоинт `GET /case/1/getData`.
2. **Обработка и память:** По запросу `POST /run` модуль памяти анализирует 90-дневную ленту событий, формирует ответы на вопросы и определяет набор виджетов (от 1 до 4 шт.).
3. **Валидация:** Итоговый JSON автоматически собирается и проверяется на соответствие контракту `Case1Answers.schema.json`.
4. **Рендеринг:** Фронтенд-приложение получает декларативное JSON-описание и динамически собирает экран утра.

---

## Производительность и ограничения

Система спроектирована с учетом строгих инфраструктурных и API-ограничений хакатона:
* **Оперативная память (RAM):** оптимизировано до **≤ 512 МБ**.
* **Время выполнения пайплайна:** стабильная обработка в пределах **45 минут**.
* **Квоты LLM (`gpt-6-luna`):** соблюдение лимитов **30 RPM** (запросов в минуту) и **300 000 токенов** за счет умного батчинга.

## 💻 Быстрый запуск

### Backend (FastAPI)
```bash
# Клонирование репозитория
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>

# Установка зависимостей
python -m venv venv
source venv/bin/activate  # для Windows: venv\Scripts\activate
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env

# Запуск сервера
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Frontend (React + Галерея виджетов)
```bash
cd frontend
npm install
npm run dev
```
> **Примечание:** Для демонстрации перед жюри в веб-интерфейсе доступна специальная **галерея всех 12 виджетов**, позволяющая просмотреть каждый компонент каталога независимо от текущего сценария.
